# 更新记录

## v0.23 · 2026-11-08

- 滑动抛竿改为按距离调整力度；停止滑动不再暗中继续蓄力，回滑可以减力。
- 保留按住蓄力，按住转滑动时维持力度连续，减轻突跳。
- 普通鱼获、鱼王、珍珠和杂物结果弹窗只能通过明确操作按钮关闭。
- 增加 350 毫秒防连点保护，并要求在按钮上产生新的按下动作，避免上一轮残留点击误关结果。
- 保留 v0.22 音效和性能优化。
