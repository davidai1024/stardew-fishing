# 星露谷钓鱼

面向手机触屏的星露谷钓鱼小项目，包含原版地图风格、滑动抛竿、鱼王试钓、鱼获收集和渔具升级。当前版本 **v0.23**，基于 v0.20 小红书上传包迭代。

## 本次版本

- 滑动距离决定抛竿力度；停住保持，向回滑动减力，预览与实际落点一致。
- 鱼获结果弹窗仅通过操作按钮关闭，并拦截连续点击产生的误触。
- 中鱼提示和滑动音效更柔和；停止滑动后不持续嗡鸣。
- 缓存地图静态层、水面状态、缩略图及部分界面计算，减少重复绘制和布局读取，保留原有画风、素材与画布分辨率。

## 本地运行

需要 Python 3。在仓库根目录运行：

```sh
python3 -m http.server 8000 --directory game
```

浏览器打开 <http://localhost:8000>。移动端布局可用浏览器设备模拟查看。浏览器模式使用本地存储；小红书容器内优先使用平台存档接口。两种环境的存档不自动互通。音乐和音效需要用户点击后才能播放。

`game/` 已包含完整运行文件，无需安装前端依赖。请通过本地服务运行，避免直接双击 HTML 造成浏览器资源或存储限制。

## 修改与打包

```sh
# 校验 src 与运行包一致
python3 scripts/build.py --check

# 修改 src 后重建 runtime.js，并生成小红书上传 ZIP
python3 scripts/build.py
```

输出为 `dist/stardew-fishing-v0.23-xiaohongshu.zip`，ZIP 根目录直接包含 `index.html`、`runtime.js`、`style.css`、`art/` 和 `music/`。

- `src/`：拆分后的 JavaScript 源码，加载顺序由 `order.json` 维护。
- `game/`：运行入口、样式、素材及生成的 `runtime.js`。
- `scripts/build.py`：无需额外依赖的构建和打包脚本。
- `docs/`：更新记录、验证说明和素材来源。

修改逻辑请编辑 `src/`，再运行构建；修改页面和样式请编辑 `game/index.html` 与 `game/style.css`。升级版本时同步修改构建脚本中的版本号和更新记录。
